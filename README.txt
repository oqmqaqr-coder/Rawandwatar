خطوات النشر على GitHub Pages
1) افتح المستودع Rawandwatar/oqmqaqr-coder (يجب أن يكون Public).
2) Add file ثم Upload files، واسحب كل الملفات الموجودة داخل هذا المجلد (وليس المجلد نفسه) ثم Commit changes.
3) Settings ثم Pages: اختر Branch = main والمجلد / (root) ثم Save.
4) بعد دقيقة افتح الرابط في Chrome على الهاتف ثم القائمة (⋮) ثم تثبيت التطبيق.
البيانات تبقى على الهاتف فقط. خذ نسخة احتياطية يومياً من أسفل الصفحة الرئيسية.
